### **STEP 3: Add Custom Domain Mapping**
After DNS records are added, run this command:

```bash
# Map custom domain to Cloud Run frontend
gcloud run domain-mappings create \
  --service=frontend \
  --domain=infinityai.pro \
  --region=us-central1

# Also map www subdomain
gcloud run domain-mappings create \
  --service=frontend \
  --domain=www.infinityai.pro \
  --region=us-central1
```
