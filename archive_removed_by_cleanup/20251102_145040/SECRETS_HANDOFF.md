# Secrets handoff and remediation

This document explains the changes made to remove plaintext secrets from the repository and how to securely store and reference secrets for InfinityAI.Pro.

Why this change
- Several files previously contained literal API keys (Gemini/Google keys). Storing secrets in the repo is a security risk.

What I changed
- `gemini-config.env` — removed literal API keys and left a template with empty fields and guidance.
- `gemini-api-config.json` — removed key values and replaced with `null` + a `secret_names` map.
- `gemini.env` — updated to reference a secret name constant instead of a value.
- `firebase_functions_list.txt` — populated with exported function names for convenience.

Recommended secret storage
1. Google Secret Manager (recommended for GCP deployments)
   - Create secrets:
     - `GEMINI_API_KEY_PRIMARY`
     - `GEMINI_API_KEY_SECONDARY`
   - Grant access to the service accounts that need them (e.g., Cloud Run service accounts, Cloud Functions runtime service account).
   - In code, fetch with the GSM client (examples in `engines/*/core/config.py` or add helper `get_secret(name)`).

2. GitHub Actions / Vercel / Northflank
   - Store secrets in GitHub repository secrets (or organization secrets) for CI/CD: `GEMINI_API_KEY_PRIMARY`, etc.
   - For Vercel, set Environment Variables in the Vercel dashboard.
   - For Northflank, use the platform's secret store and set the secret in the service environment.

Local development
- Use a local `.env` (which is in `.gitignore`) or set environment variables in your shell. Example:

```powershell
# PowerShell
$env:GEMINI_API_KEY_PRIMARY = "<your-key-here>"
# or using .env + direnv / dotenv
```

Rotating exposed keys
- If keys were ever pushed to a public or shared repository, rotate them immediately in the provider console and update the new secrets in GSM / GitHub Secrets.

Verification checklist
- [ ] Remove any other plaintext API keys found in the repo (search for `AIza` or other key patterns).
- [ ] Confirm `GEMINI_API_KEY_PRIMARY` exists in GSM and repository secrets.
- [ ] Confirm services (Cloud Run, Cloud Functions) have access to the secrets.
