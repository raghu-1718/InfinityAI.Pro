⚠️  RATE LIMITING RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Allowed:     100 requests per minute per IP
Exceeding:   Returns 429 Too Many Requests
Ban:         5 minutes after limit exceeded
Reset:       Automatic after ban expires

How to handle in code:
  if response.status_code == 429:
      wait_time = int(response.headers.get('Retry-After', 300))
      time.sleep(wait_time)  # Wait and retry

Best practice: Batch symbols in single request
  Instead of: {"symbols": "GOLD"}, {"symbols": "CRUDE"}
  Use this:   {"symbols": "GOLD,CRUDE"}  ← Faster + no rate limit issues

Q: Getting 401 Unauthorized?
A: Check your API key is correct and set in Authorization header

Q: Getting 429 Too Many Requests?
A: You've exceeded 100 requests/minute. Wait 5 minutes or use backoff.

Q: Requests are slow (> 5 sec)?
A: Try batching symbols: "GOLD,CRUDE" instead of separate requests

Q: How do I get my API key?
A: Cloud Console > APIs & Services > Credentials > "InfinityAI Backtest API Key"

Q: Need more requests/minute?
A: Contact admin to increase rate limit

Q: Dashboard not showing data?
A: Wait 5-10 minutes after first request for metrics to appear
